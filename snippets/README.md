# Snippets

Google Sheets remains the editable source for snippets, aliases, category tabs,
Inbox, nested fields, URLs, and placeholders. Do not commit exported personal
or clinical snippet contents. The existing Windows and Mac implementations stay
in `windows/` and `mac/`; a shared-code rewrite is not required for consolidation.

Dell legacy hotstrings and remaps remain local pending explicit migration of
those helpers. Their current shortcuts are listed in `windows/DELL-INVENTORY.md`.
